# L6 — Data I/O and preprocessing (reviewer L6, 2026-10-09)

Scope: src/batchdx/cyto/io/*, src/batchdx/cyto/preprocess/*, workflow/scripts/peacoqc_qc.R, simulate.py, examples.py, data/metadata/cytobatchflagr_spectral. Read-only. Literature or tool-behaviour statements marked "(from memory, to verify)" were not checked against a source in this review.

## Verdict
1. The shipped code is honest about its scope: preprocessing is a library, not a stage, and RELEASE/implementation_status say so (docs/implementation_status.md:34,139). No false "wired" claim found.
2. Raw-FCS preprocessing (gating, asinh, PeacoQC) has no caller in the workflow or pipeline (L6-02). Handoff B2 "not started" is accurate. The FCS route of `load_dataset` loads raw channel values and nothing else.
3. The sibling claim is verified: `acquisition_order` is `arange(n)`, `Time`/`$TIMESTEP` are never read, and the drift detector labels the column "time channel recorded at ingestion" (L6-01).
4. The FCS reader is thin: it discards `$PnE`, `$PnG`, `$SPILLOVER`, `$TIMESTEP`, `$PnS` consistency and `$CYT`, and reads flowio's unpreprocessed `events` (L6-03, L6-04). Fine for pre-gated, unmixed, linear data (the spectral subset) but not a general loader.
5. Latent bug: the removal-log check in `load_dataset` rejects exactly the logs a survivors-only baseline would produce (L6-05); no test or caller exercises it.
6. The processing manifest can only express one scalar cofactor, so per-channel cofactors (conventional flow; mass 5 vs flow ~150-ish, from memory, to verify) cannot be declared or inverted (L6-06).
7. Modality gaps are total, not partial: nothing for bead normalisation, debarcoding, compensation, spillover handling, MFI normalisation, unmixing or AF handling, and `modality` is not a config concept (L6-09, L6-10, L6-11). These are scoping decisions (input is assumed preprocessed) but the package should say it cannot ingest raw mass or raw flow data.
8. Event identity and removal accounting, error-refusal style, hashing and PeacoQC wrapping are well done at unit level; the weak points are integration (not run end to end) and metadata fidelity.
Counts: 0 blocker, 7 major (L6-01..06, 09), 5 minor (07, 08, 10, 11, 12), 2 nit (13, 14). L6-09 is a capability gap against the "complete package" target rather than a defect in shipped claims.

## What is solid
- Refusal-first design: missing channels, duplicate channel names, ambiguous channel-to-feature mapping, non-finite values, unknown manifest keys, undeclared scale, `corrected=true` input and double transformation are all refused, not defaulted (src/batchdx/cyto/io/fcs.py:81-86; manifests.py:137-144,183-193; dataset.py:134-154,263-268).
- Event identity: `original_event_index` and `cell_id` are built, uniqueness-checked and propagated; PeacoQC removals are mapped through an in-file identity channel read back from the file, with length checks and an internal count reconciliation (peacoqc.py:463-486,533-562,613-618).
- PeacoQC wrapper keeps `!GoodCells`, reports a MAD-only pass honestly when the isolation tree declines, captures warnings, and refuses to treat "no R" as "no removals" (peacoqc_qc.R:23-29,165-178; peacoqc.py:583-591).
- Transform convention is stated and cross-checked: unscaled asinh with an exact inverse, the scaled-variant trap quantified, non-positive cofactors refused, logicle removed from the schema rather than accepted and ignored (transform.py:1-58,144-151).
- Gating: polygon and rectangle implemented with chained removal counted once per event; unsupported gate kinds refused by name; gates defined but not chained refused (gating.py:60-74,315-321,405-473).
- FCS write path: single-precision round-trip bound computed and asserted, existing-file overwrite refused, processing/scale keywords stamped (fcs.py:148-202).
- Binary Python/R matrix exchange is typed with a sidecar and magic string (binary.py).
- Real-data inventory is checksummed and its eligibility decision is honest (one homogeneous 24-file subset, 48 excluded for layout, no biological claim) (DATASET.md).
- Status documents match reality on B2 (implementation_status.md:34,139; handoff B2).
