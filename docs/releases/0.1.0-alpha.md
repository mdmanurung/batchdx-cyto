# Draft release text — batchdx-cyto 0.1.0 Alpha

**Draft only. Do not publish until `RELEASE.md` is signed off and the tag is approved.**

`batchdx-cyto` runs design-aware batch diagnosis, candidate correction, evaluation,
decision rules and an offline report for cytometry through Snakemake. The `0.1.0` Alpha
includes R-backed cyCombine and CytoNorm correction, CytoBatchFlagR diagnosis, a pinned
upstream audit, typed result records, and a synthetic paired-reference example. It also
includes a `none` candidate so the decision can preserve the uncorrected baseline.

The scientific tests use synthetic data. Public spectral-control FCS files have been
downloaded and audited outside Git, but no real-data correction result or cohort
calibration is included in this Alpha. Raw-FCS preprocessing is implemented as
components but is not yet connected to the workflow. The container and SLURM profile
have not been executed. FCS export and logicle are unsupported; `openproblems.cms` is
absent at the pinned upstream commit. See `docs/implementation_status.md` for the
executed gate record and `docs/blocked.md` for open work.

Install with `pip install batchdx-cyto==0.1.0` **only after publication**. Until then,
install from a reviewed checkout with `pip install -e '.[dev]'` and fetch pinned upstream
sources with `bash scripts/fetch_upstream.sh .upstream`. The isolated R runtime setup is
documented in `ENVIRONMENTS_INSTALLATIONS.md`.
